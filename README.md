# Basics of HTML

A collection of practice files from learning front-end web development — plain HTML, CSS, and vanilla JavaScript. Each file is a self-contained exercise or small demo covering a specific concept, from basic tags to small interactive projects.

## What's in here

**Day-by-day exercises** (`day1.html` … `day19.html`, with matching `.css` files such as `day6.css`, `day10.css`, etc.) — walk through core HTML/CSS/JS topics: text formatting and inline/internal/external styling, layout and lists, forms and form validation, `<details>`/`<select>`/`<iframe>` elements, dates and timers, and asynchronous API calls.

**Small demo projects:**

| File(s) | Description |
|---|---|
| `calculator.html`, `calc.css` | A basic on-screen calculator |
| `crud.html`, `crud.css`, `crud.js` | A simple Create/Read/Update/Delete app for managing a list of cars |
| `todolist.js` | A to-do list with add/remove functionality |
| `weather.js` | Fetches and displays weather data from an API |
| `addtocart.js`, `day19.html` | A shopping cart / "add to cart" counter demo |
| `fashionstore.html`, `demo.css`, `demo2.css` | A fashion e-commerce landing page layout |
| `irctc.html`, `irctc.css` | A clone of the IRCTC (Indian Railways) booking site landing page |
| `frontpage.html`, `web_frontpage.css` | A general website front page layout |
| `login.js` | Basic login form handling |
| `date.js`, `scroll.js`, `bluelinkapi.js`, `normaljson.js` | Small standalone JS snippets for dates, scroll behavior, and API/JSON handling |

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- [Font Awesome](https://fontawesome.com/) (loaded via CDN in a few pages, for icons)

No build tools, frameworks, or package manager are used — these are plain static files.

## How to run

No installation required. Clone the repo and open any `.html` file directly in a browser:

```bash
git clone https://github.com/kingofthehills/basics-of-html.git
cd basics-of-html
```

Then open a file like `day1.html`, `calculator.html`, or `crud.html` directly in your browser, or serve the folder locally (e.g. with the VS Code "Live Server" extension) for pages that fetch external resources or images.
